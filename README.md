# 🏨 Hotel Management System

A simple Hotel Management System built using Python.

## Features

* Guest information
* Room booking and availability
* Check-in and check-out
* Room charges
* Food orders
* Total bill and discount
* Show final bill

## Technologies Used

* Python

## How to Run

Run the following command in your terminal:

```bash
python "🏨 Project  5 . Hotel Management System.py"
```
